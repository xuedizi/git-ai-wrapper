# git-ai-wrapper v1.7.0-tac.v0.2.0

新增企业 checkpoint / commit 指标上报，基于上游 git-ai v1.7.0，保留 CodeBuddy preset 支持。

- 发行配置固定读取 `config/enterprise-metrics.release.json` 并构建时内嵌，默认开启，组织为 `tinnove`；终端用户无需配置。
- 用户身份来自仓库有效 `user.email`，仓库身份来自规范化 origin/唯一 remote URL；身份按事件冻结，commit_id 保留 Git SHA。
- 指标先写本地 SQLite，再由 daemon 异步上传；保留持久重试、独立确认、容量与保留期管理。
- HTTP 请求使用 `token` 请求头和 `completeData` 包装，以 HTTP 200 且 JSON `success=true` 判定成功。
- 支持 `enterprise-telemetry status / flush / retry`；未调整上游归属、blame、Git Notes 行为。

验证：2424 项库测试通过（1 项上游忽略）、5 项发行脚本测试通过、真实 checkpoint/commit 与 recovery 集成测试通过；接口模拟的两类请求均返回 200 / success=true。尚未核对服务端入库字段与幂等行为。

发布产物包括 Linux、macOS、Windows 各 amd64/arm64 六个平台归档和 SHA-256 manifest。
