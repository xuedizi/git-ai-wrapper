# git-ai-wrapper v1.7.0-tac.v0.2.2

Prepared release: CodeBuddy CN IDE can send `cwd: "/"` in hook events even
though the hook runs inside the project. The CodeBuddy preset now falls back to
the process working directory when the event directory cannot locate a Git
repository. Valid CLI event directories retain priority. The selected directory
also resolves relative edited-file paths without replacing subdirectories with
the repository root.

Includes isolated directory-selection regressions and real edit/Bash
checkpoint-to-commit attribution tests in the release test gate. Hook commands
and model extraction remain unchanged.

Publish and verify all native wrapper artifacts before releasing TCLI with this
version pin. This document does not assert that a remote release exists.
