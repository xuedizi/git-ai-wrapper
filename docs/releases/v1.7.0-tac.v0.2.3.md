# v1.7.0-tac.v0.2.3

Fix CodeBuddy CN IDE file checkpoints that remained empty after the cwd fix:
the IDE supplies `tool_input.filePath`, while the parser previously accepted
only `file_path`, `filepath`, and `path`. Accept the additional spelling without
changing existing alias precedence. This shared parser addition also benefits
other presets that use it; cwd fallback remains specific to CodeBuddy.

CodeBuddy model selection now uses an explicit hook model first. For `auto`,
try the existing CLI transcript extractor and retain `auto` if no model is
available. Missing/empty hook model fields retain the existing transcript and
`unknown` fallback. No global settings or unrelated log models are inferred.

Validation: 232 preset unit tests and 10 CodeBuddy integration tests pass,
including IDE new-file AI attribution after commit for `auto` and `glm-5.3`.
The full three-patch stack applies cleanly to upstream v1.7.0. Release CI runs
its full patch regression gate before building all six native platforms.
