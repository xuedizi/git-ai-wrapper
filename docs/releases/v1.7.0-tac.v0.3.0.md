# git-ai-wrapper v1.7.0-tac.v0.3.0

Built from upstream git-ai v1.7.0, retaining the three downstream patches in v1.7.0-tac.v0.2.3.

- TCLI-bundled GA daemons invoke the paired `tcli self-update --auto` after a randomized 60–300 second startup delay and then hourly.
- TCLI owns update checks, caching, downloads, and replacement. `TCLI_AUTO_UPDATE=0` disables the trigger.
- Bundled GA does not independently download upstream updates. Standalone GA retains upstream behavior.
- Existing `bg status`, `bg shutdown`, and `bg start` commands remain unchanged. No maintenance protocol, migration, or manifest format changes are introduced.

The TCLI automatic entry must be included in the paired TCLI release. On an older TCLI without that entry, the background invocation exits without terminal output.

Release validation requires patch regressions and native build/version smoke checks on Linux, macOS, and Windows, each for amd64 and arm64.
