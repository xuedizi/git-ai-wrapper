# v1.7.0-tac.v0.3.0

Adds TCLI-owned safe updates while preserving upstream v1.7.0 and existing CodeBuddy/enterprise behavior.

- Versioned offline identity and maintenance prepare/stop/health/resume protocol.
- Persistent admission barrier, foreground leases, graceful local drain, runtime/data-home binding, and validation startup.
- Managed builds delegate update ownership to TCLI and use its shared background check schedule.
- Retained bridge support for controlled legacy migration; no default hard kill.
- Release CI validates managed lifecycle on each of the six native runners before publication. Synthetic fixture telemetry remains disabled.

Consumers must use a compatible TCLI update worker. Initial migration from older GA requires a controlled offline maintenance window. Maintenance includes a short collection gap; this release does not promise zero-loss hot swapping.
